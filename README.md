# 🚀 My Own DSA Sheet - Ultra Minimal & Beautiful React App

An interactive, high-performance Data Structures & Algorithms (DSA) preparation tracker built with React.js, Tailwind CSS, and LocalStorage persistence.

Live Repository: [https://github.com/jayOnWeb/my_own_DSA_sheet](https://github.com/jayOnWeb/my_own_DSA_sheet)

---

## ✨ Features

- **9 Core Topic Categories**:
  - 1. Array (32 problems + 13 array patterns + Two Sum note)
  - 2. String (30 problems + matching notes)
  - 3. Stack (14 problems + 6-step monotonic stack progression)
  - 4. Queue / Deque / Heap (13 problems)
  - 5. Linked List (15 problems + 8-step pointer manipulation progression)
  - 6. Tree (23 problems + 13 traversal/BST/Trie patterns)
  - 7. Graph (23 problems + 15 graph pattern checklist entries)
  - 8. Dynamic Programming (31 problems + 17-step DP progression roadmap)
  - 9. Recursion / Backtracking (20 problems + mental model: `choose → explore → undo` + 9-step progression)
- **Direct LeetCode Links**: One-click navigation to every LeetCode problem.
- **Core 75 Essential List**: Curated view for fast revision of the 75 must-know problems.
- **Daily Streak Engine**: Tracks active streak days (🔥), maximum streak, and daily activity.
- **Progress Analytics**: Easy 🟢, Medium 🟡, Hard 🔴 breakdown bars and completion meters.
- **Notes & Bookmarking**: Star problems for revision and write approach notes saved directly in browser LocalStorage.
- **Offline Data Backup**: Export/Import `.json` backup files anytime.

## 🛠️ Local Development Setup

```bash
# Clone repository
git clone https://github.com/jayOnWeb/my_own_DSA_sheet.git

# Navigate into directory
cd my_own_DSA_sheet

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
